# CDD Lab Experiment 7: Automate Build and Testing with GitHub Actions

## Objective
Automate build and testing processes using GitHub Actions workflows.

## Duration
2 Hours

## Tasks
1. Create a sample application (e.g., Python or Node.js).
2. Write unit tests.
3. Create a GitHub Actions workflow that:
   - Builds the application
   - Runs the tests
   - Reports results
4. Configure the workflow to run on every push.

## Expected Outcome
Automated build and test pipeline that passes on successful code and fails on broken tests.
